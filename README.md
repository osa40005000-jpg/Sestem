# تطبيق دردشة أندرويد (بين اتنين)

تطبيق بسيط: كل واحد يكتب اسمه واسم صاحبه، ويدخلوا نفس الغرفة ويتكلموا فورًا.
مفيش حسابات ولا باسورد، فهو مناسب للتجربة والاستخدام الشخصي بين صحاب.

## الخطوة 1: إنشاء مشروع Firebase (مجاني)

1. افتح https://console.firebase.google.com وسجّل بحساب Google.
2. اضغط **Add project** واكتب أي اسم، وكمّل (ممكن تقفل Google Analytics).
3. من القائمة الجانبية: **Build ← Firestore Database ← Create database**.
4. اختار **Start in test mode** واضغط Next ثم Enable.
   (وضع الاختبار بيسمح لأي حد يقرأ ويكتب لمدة 30 يوم، وبعدها لازم تعدّل القواعد.)

## الخطوة 2: ربط التطبيق بـ Firebase

1. في صفحة المشروع اضغط أيقونة **Android** لإضافة تطبيق.
2. في خانة Android package name اكتب: `com.example.chat_app`
3. اضغط Register app، وفي الآخر هتلاقي بيانات المشروع.
4. من **Project settings ← General** هتلاقي القيم دي:
   - `apiKey`
   - `appId`
   - `messagingSenderId`
   - `projectId`
5. افتح الملف `lib/main.dart` وبدّل القيم اللي مكتوب فيها "ضع_..._هنا" بالقيم دي.

## الخطوة 3: بناء ملف التطبيق (APK) من غير تنزيل برامج

1. سجّل في https://github.com وأنشئ **New repository** (خليه Private لو تحب).
2. ارفع كل ملفات المشروع (اسحبهم في صفحة الـ repository)، **مع مجلد `.github`**.
3. افتح تبويب **Actions** وستلاقي عملية **Build APK** شغالة تلقائيًا.
4. استنى حوالي 5 إلى 10 دقايق لحد ما تبقى علامة صح خضرا.
5. افتح العملية، ونزّل **chat-apk** من قسم Artifacts في الآخر.
6. فك الضغط هتلاقي `app-release.apk`، ابعته لموبايلك وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## الاستخدام

- افتح التطبيق على موبايلين.
- الأول يكتب اسمه "أحمد" واسم صاحبه "محمد"، والتاني يكتب "محمد" و"أحمد".
- هيدخلوا نفس الغرفة والرسائل بتوصل فورًا.

## ملاحظات

- لازم إنترنت على الموبايلين.
- لو عايز حسابات وباسورد وإشعارات بعدين، قولي وأضيفها.
